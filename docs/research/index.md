# 研究方向

我的研究围绕**计算流体力学（CFD）**及其在能源工程中的应用展开，核心是**气固两相反应流**的数值模拟、**风能利用**，以及**高性能计算与机器学习**方法。

## 主要方向

- [CFD-DEM 气固两相流](cfd-dem.md) —— 流化床、气化、化学链等反应性颗粒流模拟
- [风能与风电场](wind-energy.md) —— 尾流模型、风电场布局优化与功率预测
- [GPU 计算与机器学习](gpu-ai.md) —— CUDA 并行与 Neural Operator 等数据驱动方法

## 研究关键词

RANS · Navier-Stokes 方程 · CFD-DEM · 流化床 · 气化 · 化学链 · 尾流模型 · Neural Operator · CUDA
