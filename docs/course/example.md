# 示例课程文档：一篇文章应该怎么写

这是一篇示例文档，用来告诉你以后写课程文章时可以按什么格式来写。

## 1. 标题怎么写

用 `#` 表示标题。一个 `#` 是最大的标题（页面大标题），两个 `#` 是第二级标题，三个 `#` 是第三级，依此类推。

## 2. 普通段落怎么写

直接写文字就是一段，两段之间记得空一行，看起来更清楚。

## 3. 列表怎么写

用 `-` 加空格可以写列表：

- 第一条内容
- 第二条内容

## 4. 代码怎么写

把代码放在三个反引号 ` ``` ` 中间，就会显示成代码块：

```python
print("你好，世界！")
```

## 5. 提醒框怎么写

Material 主题自带漂亮的提醒框，比如"提示"和"注意"：

!!! tip "提示"
    这是一条提示内容。

!!! note "注意"
    这是一条注意事项。

## 6. 怎么写新文章

1. 在 `docs/course/` 文件夹里新建一个 `.md` 文件。
2. 文件最开头按本文的格式写上 `title` 和 `date`。
3. 保存后，浏览器会自动刷新，不需要重启网站。
