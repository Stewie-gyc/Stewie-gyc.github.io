# 训练计划

基于 9 月 15 日的盘点定的草案：引体要冲 12，背要加厚（菱形肌、中下斜方），卧推继续加片，俯卧撑补上。

## 每周安排

| 星期 | 内容 | 重点 |
| :--- | :--- | :--- |
| 周一 | 推：胸、肩、三头 | 卧推主项 |
| 周二 | 拉：背、二头 | 引体专项，背部厚度 |
| 周三 | 休息 / 有氧 | 走路、慢跑、拉伸 |
| 周四 | 腿 | 深蹲、臀腿 |
| 周五 | 上肢综合 | 引体容量 + 后束、菱形肌 |
| 周六 | 有氧 / 核心 | 悬垂举腿、平板 |
| 周日 | 休息 | 睡够，吃够 |

场地不挑：自由重量、固定器械、自重（引体、俯卧撑）都能用。一周 4–5 练，每次 60–75 分钟。练不动就减一组，别硬凑。

## 动作库

### 拉（背部优先）

| 动作 | 组数 × 次数 | 说明 |
| :--- | :--- | :--- |
| 引体向上 | 4 × 4–6 | 主项。力量日加负重，容量日冲次数 |
| 高位下拉 | 3 × 8–12 | 找背阔肌发力，别用手臂拽 |
| 坐姿划船 | 3 × 8–12 | 肩胛后缩，停顿一秒 |
| 单臂哑铃划船 | 3 × 10–12 | 拉到腰侧，别耸肩 |
| 面拉（绳索） | 3 × 15 | 菱形肌、中下斜方，重量小一点 |
| 反向飞鸟 | 3 × 12–15 | 后束，收尾用 |
| 直臂下压 | 3 × 12 | 背阔肌孤立 |

### 推（胸、肩、三头）

| 动作 | 组数 × 次数 | 说明 |
| :--- | :--- | :--- |
| 卧推 | 4 × 5–8 | 70 kg 做组，做满区间上限再加 2.5 |
| 实力推 | 3–4 × 6–10 | 站姿，当前 30 kg，核心收紧别后仰 |
| 上斜哑铃卧推 | 3 × 8–10 | 上胸 |
| 侧平举 | 3 × 12–15 | 肩中束 |
| 双杠 / 俯卧撑 | 3 × 力竭 | 顺带把俯卧撑补了 |
| 绳索下压 | 3 × 12 | 三头 |

### 腿

| 动作 | 组数 × 次数 | 说明 |
| :--- | :--- | :--- |
| 深蹲 / 腿举 | 4 × 6–10 | 主项 |
| 罗马尼亚硬拉 | 3 × 8–10 | 后链 |
| 腿弯举 | 3 × 12 | 腿后侧 |
| 提踵 | 3 × 15 | 小腿 |

## 引体突破方案

- **力量日**（周二）：负重 4 × 3–5，组间 2–3 分钟
- **容量日**（周五）：自重 5 × 5–8，组间 90 秒
- 次数稳定到区间上限就加重量或加组
- 拉不上去的日子做离心：跳上去，慢慢放 5 秒 × 5

## 进阶规则

1. 同一重量做满次数区间上限，下次加 2.5 kg（大肌群）或 1–2 kg（小肌群）。
2. 连续两次达不到区间下限，减 10% 重量重来。
3. 组间休息：主项 2–3 分钟，孤立动作 60–90 秒。
4. 每天记重量和次数，不然不知道自己有没有进步。

## 恢复与饮食

- 睡眠 7–8 小时，早起但别在床上磨时间
- 蛋白质 1.6–2.0 g/kg 体重，分 3–4 餐
- 早餐固定：燕麦 + 无糖酸奶（可加蛋白粉）
- 训练后 1 小时内补碳水和蛋白
- 每天喝水 2.5–3 L，补剂按时吃
